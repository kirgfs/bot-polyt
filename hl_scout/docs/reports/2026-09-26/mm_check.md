## Как считалось

- Прибыль на $1 оборота = PnL за месяц / оборот за месяц из строки лидерборда (1 б.п. = 0.01%). До комиссий она не больше этого плюс taker 4.5 б.п.: дороже taker никто не платит.
- Допущение: копия с задержкой в среднем входит не лучше трейдера, поэтому её доход до комиссий не выше.
- Копия сделки = размер их сделки × $50 / капитал торгующего адреса: копия держит то же плечо.
- «Если докупать до $15» — настройка «Your Copy Size < $15 → Buy»: каждая мелкая сделка становится ордером $15, оборот и издержки считаются по их числу сделок в день.
- Доля лимиток, сделки в день и размеры — по последним филлам торгующего адреса (`userFills`, до 2000).
- Полный walk-forward для них невозможен: API отдаёт только 10 000 последних филлов, у них это часы.
