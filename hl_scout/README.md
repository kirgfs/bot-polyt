# hl_scout — скаут кошельков Hyperliquid perps для copy-бота

hl_scout **не торгует, не копирует и не шлёт сигналы по сделкам**. Копирует сторонний copy-бот. Скаут отвечает только на три вопроса:

1. **СЛЕДИТЬ** — какой кошелёк копировать и с какими настройками copy-бота под мой депозит ($50).
2. **ВНИМАНИЕ** — у отслеживаемого кошелька появились ранние признаки проблем.
3. **ПРЕКРАТИТЬ / ЗАМЕНИТЬ** — отписаться (и на кого заменить).

Нужен только публичный Info API и WebSocket Hyperliquid. Приватные ключи не нужны и не запрашиваются.

## Статус

| Этап | Что | Состояние |
|---|---|---|
| 1 | discovery → фильтры и score → копируемость на $50 → walk-forward → Monte Carlo → отчёт по топ-10 | ✅ код и офлайн-тесты |
| — | Реальный отчёт по топ-10 | ⏳ нужен запуск с доступом к `api.hyperliquid.xyz` (см. ниже) |
| 2 | Telegram (aiogram 3): СЛЕДИТЬ / ВНИМАНИЕ / ПРЕКРАТИТЬ, команды, monitor, paper 14 дней, «НАСТРОЙКИ» | 🔜 после реального отчёта и документации copy-бота |

## Честно о цели $1000 за 30 дней

- $50 → $1000 за 30 дней — это ×20, то есть около +10.5% **каждый день** месяц подряд.
- Скаут не подгоняет параметры под эту цифру. Он показывает её **вероятность** из Monte Carlo по out-of-sample результатам копирования.
- На любых реалистичных данных, в том числе на синтетическом «очень хорошем» трейдере из тестов, эта вероятность близка к нулю.
- Приоритет настроек — не потерять депозит. Главная защита: Balance SL на $30 и потолок убытка проекта −$20.

## Установка на Windows

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/windows/). В установщике отметьте **Add python.exe to PATH**.
2. Откройте PowerShell в папке `hl_scout` и выполните:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1          # если ругается на политику: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
pip install -e ".[dev]"
copy .env.example .env               # токен Telegram понадобится на этапе 2
```

Русский текст в консоли лучше смотреть в **Windows Terminal**. В старом `cmd` сначала выполните `chcp 65001`.

## Запуск

```powershell
# 1. Сверить факты об API с живым API (docs/api_notes.md §9)
python -m hl_scout selfcheck

# 2. Полный цикл: сбор кандидатов → фильтры → score → бэктест → отчёт по топ-10
python -m hl_scout report --top 10

# повторный отчёт без сети, только по кэшу
python -m hl_scout report --skip-discovery

# полный разбор и бэктест любого адреса (в том числе найденного вами)
python -m hl_scout check 0xВАШ_АДРЕС

# только сбор данных (например, по расписанию раз в сутки)
python -m hl_scout discover --listen-min 15
```

- Отчёт появляется в консоли и в файлах `reports/top10_ГГГГММДД_ЧЧММ.md` и `.json`.
- Логи пишутся в `logs/hl_scout.log` (JSON).
- Кэш хранится в `data/hl_scout.sqlite`.

**Сколько это займёт.**
- Лимит Info API — 1200 weight в минуту на IP. hl_scout держит 1000, чтобы оставить запас.
- Первый полный `report` при настройках по умолчанию занимает порядка часа:
  - 400 адресов на стадии 1;
  - до 150 адресов на полной загрузке;
  - свечи и funding по их монетам;
  - 10 минут прослушивания крупных сделок.
- Следующие запуски докачивают только новое.
- После загрузки анализ (walk-forward топ-10, сравнение 1×$50 и 2×$25, проверка всего процесса) идёт локально ещё 10–20 минут.
- Размер пула меняется в `config.yaml` → `discovery.pool_max` / `deep_max`. Сетка перебора настроек — `backtest.grid`.

## Что внутри отчёта

- **Воронка:** сколько кошельков отсеял каждый жёсткий фильтр.
- **Топ-10 по score:**
  - Deflated Sharpe (навык против удачи с поправкой на число проверенных кошельков), Sortino, profit factor, доля недель в плюс, просадка;
  - копируемость на $50;
  - доля прибыльных тестовых окон;
  - P(обнуление), P(≥ $100), P(≥ $1000), медиана на 30 дней, уровень риска.
- **По каждому кошельку:**
  - стиль торговли;
  - блок «Копируемость на $50»: доля повторимых действий, асимметрия пропусков, одновременные позиции, лестница входа, запас до ликвидации, «стоп выбивал бы зря», доля издержек;
  - три профиля настроек copy-бота (консервативный / средний / агрессивный) с прогнозом Monte Carlo;
  - таблица walk-forward.
- **1 кошелёк на $50 vs 2 кошелька по $25.**
- **Проверка всего процесса:** на каждую дату в прошлом кошелёк выбирается только по данным до неё — сколько дало бы следование скауту.

Если никто не проходит проверки, отчёт так и говорит: «Рекомендовать некого».

## Настройки

- `config.yaml` — все пороги: фильтры, score, сетка настроек бэктеста, профили риска, правила ВНИМАНИЕ/ПРЕКРАТИТЬ, Monte Carlo, лимиты API. У каждого параметра есть комментарий.
- `copybot_fields.yaml` — поля вашего copy-бота в порядке меню и их семантика: как считается ratio, что делает «< $10», как работает Balance SL. **Сейчас это рабочие допущения**, и бэктест считает по ним. Пока нет документации бота:
  - сообщение «НАСТРОЙКИ» не выдаётся;
  - комиссия бота консервативно принята 0.1% за сделку.
- `.env` — только токен и chat id Telegram (этап 2). Ключи Hyperliquid не нужны.

## Структура

```
src/hl_scout/
  hl/client.py        Info API: rate limit по weight, ретраи, пагинация (2000 филлов / 500 записей / 5000 свечей)
  hl/ws.py            WebSocket: крупные сделки (trades.users), позже — userFills для monitor
  store.py            SQLite-кэш (WAL), инкрементальная докачка
  discovery.py        пул по активности → portfolio-скрининг → полная загрузка
  analytics.py        филлы → действия → сделки → позиции; кривая капитала из portfolio
  detectors.py        мартингейл, маркет-мейкер, ликвидационный бот, хеджи, связанные кошельки
  stats.py            Sortino, profit factor, Deflated Sharpe, bootstrap p-value, BH
  scoring.py          жёсткие фильтры и score «на дату»
  market.py           свечи разных интервалов, funding, режим рынка
  sim.py              симуляция МОЕЙ копии через copy-бот
  replicability.py    раздел 2.5: копируемость на $50
  rules.py            ВНИМАНИЕ / ПРЕКРАТИТЬ / ПАУЗА (общие для бэктеста и monitor)
  backtest.py         walk-forward, сетка настроек, 3 профиля, подбор порогов правил
  montecarlo.py       блочный бутстрап капитала на 30 дней
  pipeline.py         весь анализ + walk-forward всего процесса
  report.py           Markdown и JSON отчёт
  cli.py              python -m hl_scout …
```
